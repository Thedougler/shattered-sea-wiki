# Tail Staging Island

## Situation

The primary staging point for [[Shelfworks]] salvage is the closest inhabited Tail island to the Maw's western edge. It is intentionally unnamed and undetailed until the campaign needs a resupply stop, salvage-camp settlement, factional pressure point, or hard-weather refuge.

## Current State

Not yet fixed in public canon. Keep the blank deliberate so the island can absorb whatever pressure the Shelfworks arc requires without duplicating an existing Tail settlement.
