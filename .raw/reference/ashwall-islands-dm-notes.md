# Ashwall Islands — DM Notes

## Design Intent

Intentionally under-detailed — use as western orientation point and late-campaign expansion space, not a near-term destination.

Pilot lore that the Galewall is sustained by arclight-phoenix activity should be treated as substantially true in-setting.

## Development Levers

If the party pushes west: hostile-weather expedition zone; Selune navigation-cult stronghold; staging point for Galewall crossing arcs.
