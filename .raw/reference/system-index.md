# System Index

> Agent use: Start here when locating agent-facing system guides and templates.

## Template-First Rules

- Create or revise the template before changing repeated system-doc structure.
- Prefer compact sections: `Agent use`, `Use When`, `Core Rules`, `Procedure`, `Output Shape`, `Related`.
- Keep system docs scannable; move long examples to source/raw pages unless they are required at generation time.
- Stamp every system doc with `template`, `system_role`, and `token_profile`.
