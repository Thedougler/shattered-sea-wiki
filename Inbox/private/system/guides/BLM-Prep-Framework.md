# BLM Prep Framework

> Agent use: Read before generating session prep, NPC toys, faction pressure, or reactive scenario structures.

## Fast Rules

- Prep reactive toys, not predicted outcomes.
- Every toy needs goal, method, active problem, and performance hooks.
- Build tentpoles, then reskin details around player choices.
- Tie major prep to at least one player gravity well.


Technical analysis of Brennan Lee Mulligan's preparation methodology, as used in Dimension 20. Governs the `prep-content` skill's approach to content generation.

## Core Philosophy: Functional Preparation

Reject outcome-based prep ("what happens if players do X"). Instead, prepare **reactive systems** — elements with enough internal logic to respond to any player choice. The world acts autonomously; the GM adjudicates rather than narrates.

## The Toy Method

Every prep element — NPC, faction, location — is a **"toy"**: something that can act or react on its own initiative. Each toy requires four fields:

| Field | Definition | Implementation |
|---|---|---|
| **Primary Goal** | What it wants; a movement toward change | Define a vector, not a static condition |
| **Consistent Method** | How it pursues the goal; tactics and constraints | Does it bribe, fight, or hide? |
| **Active Problem** | Current pressure progressing without player involvement | Must create urgency independent of PCs |
| **Performance Hooks** | Two cues for instant roleplay recall | One physical habit + one speech pattern |

**Extended toy categories:**

| Type | Prep Focus | How it Acts |
|---|---|---|
| NPC | Motivation + immediate complication | Reacts to players via personality and pressure |
| Faction | Objectives + tactics | Changes world state off-screen between sessions |
| Location | Systemic function + unstable condition | Presents evolving environmental pressures |
| Encounter | Thematic goal + one terrain shift | Adapts mid-combat for narrative tension |

## Narrative Architecture: Tentpoles

Build the campaign around **fixed narrative islands** — detailed set pieces that exist in a flexible position until the players "land" on them. Between islands, the path is improvised.

### Anti-Railroading Loop

[[content/shattered-sea/private/system/guides/Session-Zero|Session Zero]] → identify player character goals and fears → build world conflicts around those → players are naturally motivated to push the "red buttons" the GM has prepped. Freedom is real; the rails are invisible.

### Schrödinger's RPG (Reskinning)

A prepped encounter exists in an undetermined location until the players approach it. If players go to Town B instead of Town A, the wizard's tower is in Town B. No prep is wasted. Requires a "loose grip" on geography.

**World model:** Mile wide, inch deep. Tone and character-response consistency > logistical realism.

## Mechanic Theatricalization

### Box of Doom Principles

Public rolls for high-stakes moments serve three functions:

1. Eliminate fudging — builds trust that danger is real
2. Create shared dramatic climax — GM declares DC + consequences *before* rolling
3. Dice as collaborator — dice govern ~20% of outcomes to inject genuine uncertainty

### Degrees of Success

For investigation/social rolls, prep multiple DC thresholds (e.g., 10/15/20). Low rolls give a crumb that keeps the story moving; high rolls reveal deeper secrets. No dead-ends from failed rolls.

### Resource-for-Advantage Trade

Players may sacrifice hit points or spell slots to gain advantage on personally meaningful rolls. Turns mechanics into high-stakes narrative bets.

## Strong Start Protocol

Begin every session with an active scene demanding character response — not an out-of-character recap. "Dig a hole the players can jump into." The Strong Start establishes current stakes emotionally before any exposition.

## Player Gravity Integration

All NPC and encounter generation must be anchored to **at least one character's backstory**. The "Link of Relevance" is a required output field. See [[Player-Gravity-Wells]] for the current gravity map.
