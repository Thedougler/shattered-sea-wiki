# Cartographer's Table

*Ship upgrade — navigation*

**[HB] Price: 8,000 gp** | Available at [[cats-curios|Cat's Curios]]

A fixed chart table installed below deck that records the ship's route in real time. Produced charts are accurate and saleable.

## Properties

- Automatically maps the ship's route in real time.
- Charts produced by the table sell for 50–200 gp each to merchants and pilots.
- Does not function over the Drowned Maw below 200-foot depth.
