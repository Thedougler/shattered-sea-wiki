# BLM Prep Framework

> Agent use: Read before generating session prep, NPC toys, faction pressure, or reactive scenario structures.

## Fast Rules

- Prep reactive toys, not predicted outcomes.
- Every toy needs goal, method, active problem, and performance hooks.
- Build tentpoles, then reskin details around player choices.
- Tie major prep to at least one player gravity well.

## Core Philosophy

Reject outcome-based prep ("what happens if players do X"). Instead, prepare **reactive systems** — elements with enough internal logic to respond to any player choice. The world acts autonomously; the GM adjudicates rather than narrates.

## The Toy Method

Every prep element — NPC, faction, location — is a **toy**: something that can act or react on its own initiative.

| Field | Definition |
|---|---|
| **Primary Goal** | What it wants; a movement toward change — a vector, not a static condition |
| **Consistent Method** | How it pursues the goal — does it bribe, fight, or hide? |
| **Active Problem** | Current pressure progressing without player involvement; creates urgency independent of PCs |
| **Performance Hooks** | Two cues for instant roleplay recall — one physical habit + one speech pattern |

| Type | Prep Focus | How it Acts |
|---|---|---|
| NPC | Motivation + immediate complication | Reacts via personality and pressure |
| Faction | Objectives + tactics | Changes world state off-screen between sessions |
| Location | Systemic function + unstable condition | Presents evolving environmental pressures |
| Encounter | Thematic goal + one terrain shift | Adapts mid-combat for narrative tension |

## Narrative Architecture: Tentpoles

Build around **fixed narrative islands** — detailed set pieces in a flexible position until players "land" on them. Between islands, the path is improvised.

**Anti-Railroading Loop:** Session Zero → identify player character goals and fears → build world conflicts around those → players are naturally motivated to push the prepped buttons. Freedom is real; the rails are invisible.

**Schrödinger's RPG:** A prepped encounter exists in an undetermined location until players approach it. If players go to Town B instead of Town A, the wizard's tower is in Town B. No prep is wasted. Requires a "loose grip" on geography. World model: mile wide, inch deep — tone and character-response consistency over logistical realism.

## Mechanic Theatricalization

**Box of Doom:** Public rolls for high-stakes moments eliminate fudging, create shared dramatic climax (declare DC + consequences *before* rolling), and let dice govern ~20% of outcomes.

**Degrees of Success:** For investigation/social rolls, prep multiple DC thresholds (e.g. 10/15/20). Low rolls give a crumb that keeps the story moving; high rolls reveal deeper secrets. No dead-ends from failed rolls.

**Resource-for-Advantage Trade:** Players may sacrifice hit points or spell slots to gain advantage on personally meaningful rolls — turns mechanics into high-stakes narrative bets.

## Strong Start Protocol

Begin every session with an active scene demanding character response — not an out-of-character recap. "Dig a hole the players can jump into." The Strong Start establishes current stakes emotionally before any exposition.

## Player Gravity Integration

All NPC and encounter generation must anchor to **at least one character's backstory**. The Link of Relevance is a required output field.
